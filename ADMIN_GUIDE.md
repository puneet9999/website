## 🎨 Design & Color Customization

### Features:
- ✅ **Primary Colors:**
  - Primary Dark Color (Default: #1a1a1a)
  - Accent Orange Color (Default: #d97d53)
  
- ✅ **Secondary Colors:**
  - Background Color (Default: #f8f8f8)
  - Text Secondary Color (Default: #666666)

  - Main Font Size (Body) - Default: 16px
  - Heading Font Size - Default: 32px

  - Real-time color picker
  - HEX code display
  - Save changes button
  - Reset to default option

### How to Change Colors:
1. Click on the color input field
2. Select your desired color
3. Click "Save All Changes"
4. Changes apply immediately

## 📋 Columns & Fields Management

### Features:
- ✅ **Projects Table Columns:**
  - Toggle: Project Name, Location, Status, Units, Year
  - Add new columns
  
- ✅ **Properties Table Columns:**
  - Toggle: Property Name, Type, Location, Price, Status
  - Add new columns

- ✅ **Create Custom Columns:**
  - Column name
  - Column type (Text, Number, Date, Dropdown, Image)
  - Select table (Projects/Properties)
  - Save custom column

### How to Add Custom Column:
1. Go to "Columns & Fields"
2. Enter column name (e.g., "Description")
3. Select column type (e.g., Text)
4. Choose table (Projects/Properties)
5. Click "Create Column"

## 🖼️ Media Manager

### Features:
- ✅ **Upload Images:**
  - Click to select image file
  - Preview before upload
  - Upload button to save
  - Supports common image formats (JPG, PNG, GIF, etc.)

- ✅ **Media Library:**
  - View all uploaded images
  - Thumbnails grid layout
  - Delete button on each image
  - Quick access to media

### How to Upload:
1. Go to "Media Manager"
2. Click "Select Image File"
3. Choose image from your computer
4. Preview appears automatically
5. Click "Upload Image"
6. Image added to Media Library

### How to Delete:
1. Find image in Media Library
2. Click "Delete" button
3. Confirm deletion
4. Image removed

## 🎯 Quick Tips

1. **Modal Forms:** Press ESC to close modal dialogs
2. **Table Actions:** Hover over rows for better visibility
3. **Color Codes:** Copy HEX codes directly
4. **Auto-save:** Many settings auto-save on change
5. **Alerts:** Success/Error messages appear at top
6. **Remember Me:** Check this box to stay logged in

## 🚀 Best Practices

1. Always save changes before navigating away
2. Upload optimized images (compressed)
3. Keep descriptions clear and concise
4. Backup data regularly
5. Change default password after initial setup
6. Test color changes on different pages
7. Delete unused media to save space
